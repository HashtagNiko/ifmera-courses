# ifmera-courses
Dieses Tool soll mit Github Pages und der Domain courses.shnoozy.top meine "Trainer-Oberfläche" darstellen.
Wichtig ist: Zugriff soll ich nur per Login erhalten. Dazu kann das Supabase Porjekt "shnoozy-App" verwendet werden, hier haben wir bereits auch schon tabellen für exams.shnoozy.top (prüfungstool, anderes Repo) eingestellt.

**Wichtig:** Es ist auf Godaddy noch keine Domain (courses.shnoozy.top) erstellt worden.
Das Tool soll mir ein Dashboard bieten, das mir alle Kurstage anzeigt, ich kann die Decks aus dem Tool direkt im Tool Öffnen (Vollbild, ohne Browserleisten) und mich mit dem Trainer-Cocpit durch die Slides klicken. Idealerweise sind hier dann auch alle Kursinhalte aus Themenübersicht Trainertagebuch - WEG-Kurs.docx hinterlrgt, damit ich sie mir Tageweise rauskopieren kann.
Dazu müssen wahrscheinlich ersteinmal alle Decks (Finale Versionen) auf Github gepusht und committet werden. Wenn an den Dateien gearbeitet wird, soll das parallel auch auf dem bereits bestehenden lokalen Ordner passieren, damit beide Orte immer synchron sind.
Als erstes sollten wir festlegen, welche Dateien in das repo kommen und dann ein gitignore erstellen, das die anderen Dateien lokal hält.
Danach testen wir das ganze mit dem WEG-Kurs.
